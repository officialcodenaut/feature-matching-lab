# Feature Matching Lab

A C++ and OpenCV project exploring local feature detection, feature descriptors, and image matching.

## Goal

The goal of this project is to understand how computer vision algorithms identify distinctive points in images and match corresponding features across different views.

The project is developed incrementally through small experiments, with a focus on understanding the underlying concepts rather than relying entirely on high-level abstractions.

## Planned Features

- [ ] Detect keypoints in images using ORB
- [ ] Visualize detected keypoints
- [ ] Compute and compare feature descriptors
- [ ] Match features between two images
- [ ] Filter matches and visualize the results
- [ ] Experiment with changes in viewpoint, scale, and lighting
